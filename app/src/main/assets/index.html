    2. Onde os arquivos vão ficar salvos?

    Escolha uma pasta de destino. O Android pedirá autorização para gravar nela.

    Nenhuma pasta de destino escolhida.

    3. Processar arquivos

    Arquivos separados: cada resultado será salvo como um .luau. ZIP: reúne os resultados em um único arquivo compactado.

    Escolha as pastas para começar.
